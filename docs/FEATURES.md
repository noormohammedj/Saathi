# Feature backlog (world-class baseline)

Inspired by the best social-discovery apps. The mechanics are similar; the brand, art and copy are our own.

## Onboarding and identity
- Phone / Apple / Google sign-in, OTP
- Guided profile builder: photos (drag to reorder), prompts, interests, lifestyle badges
- Selfie photo verification (pose match) and verified badge
- Mode selection: Date, Friends, Network

## Discovery
- Card swipe deck (like / pass / super-like), undo, physics-based animation and haptics
- Filters: age, distance, height, intentions, languages, verified only
- Daily "top picks", travel mode, incognito mode

## Matching and conversation
- Optional "first move" rule with a 24-hour countdown and one-time extension
- Real-time chat: text, voice notes, GIFs, photos, reactions, read receipts, typing indicator
- Conversation starters, in-app audio and video calls
- Unmatch, block, report from any screen

## Safety and trust
- Photo/text moderation, nude-image blur, AI-assisted message warnings
- Safety centre, emergency share-my-date, private detector settings

## Monetisation
- Premium tiers (subscription), consumables (super-likes, spotlight)
- Paywall, restore purchases, promo codes

## Platform
- Push notifications, deep links, offline cache, analytics, crash reporting, localisation, accessibility
- Admin console (web): user review queue, reports, bans, metrics
